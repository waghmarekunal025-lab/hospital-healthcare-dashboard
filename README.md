# 🏥 Hospital Healthcare Data Analysis Dashboard

A web-based **Hospital Healthcare Data Analysis Dashboard** developed using **Python, Flask, Pandas, HTML, CSS, JavaScript, and Chart.js**.

The dashboard analyzes hospital patient data and presents important healthcare statistics through interactive **KPI cards and charts**, making the data easier to understand and interpret.

---

## 📌 Project Overview

Healthcare organizations generate large amounts of patient and treatment data. Analyzing this data manually can be time-consuming and difficult.

This project provides a simple dashboard that converts hospital data stored in a CSV file into meaningful visual insights.

The dashboard displays:

* Total number of patients
* Total treatment cost
* Average patient age
* Average satisfaction score
* Inpatient and outpatient counts
* Patients by department
* Monthly patient trends
* Diagnosis distribution
* Gender distribution
* Treatment cost by department

---

## 🎯 Objectives

The main objectives of this project are:

1. To analyze hospital patient data using Python and Pandas.
2. To calculate important healthcare KPIs.
3. To visualize patient and treatment information.
4. To identify trends in hospital visits.
5. To compare departments based on patient count and treatment cost.
6. To provide an easy-to-use healthcare analytics dashboard.
